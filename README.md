# Aprendizaje Java ☕

Este repositorio reúne mis primeros pasos aprendiendo **Java**.

Aquí iré almacenando pequeños proyectos, ejercicios y programas que vaya desarrollando mientras aprendo el lenguaje. La idea es avanzar poco a poco, aplicando lo aprendido en proyectos sencillos que también puedan resultarme útiles en el día a día.

No pretende ser una colección de proyectos avanzados ni código perfecto. Es simplemente un registro de mi aprendizaje y de cómo voy mejorando con el tiempo.

## ¿Qué encontrarás aquí?

- Ejercicios para practicar conceptos de Java.
- Pequeños programas de consola.
- Proyectos sencillos aplicados a situaciones cotidianas.
- Experimentos mientras aprendo nuevas herramientas y conceptos.

Cada proyecto forma parte del camino. ☕🐧
